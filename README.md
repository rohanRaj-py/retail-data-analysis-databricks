# Retail Data Analysis using Databricks

## 📌 Overview

A retail data analysis project built using **Databricks and PySpark** to analyze Orders and Customers data.

The project covers data loading, cleaning, transformation, deduplication, data modeling, analysis, and visualization.

## 🛠️ Tech Stack

- Databricks
- PySpark
- Apache Spark
- Python
- SQL
- Delta Lake
- Git & GitHub

## 🏗️ Architecture

```text
Orders & Customers CSV
          ↓
    Bronze Layer
          ↓
    Silver Layer
   (Clean & Transform)
          ↓
     Gold Layer
  (Data Model & KPIs)
          ↓
    Visualization
